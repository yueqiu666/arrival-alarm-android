## 当前事实

应用没有账号、自建业务后端、广告或分析 SDK。提醒任务、最近地点、提醒半径和设置保存在应用私有存储中。用户可以在应用内清空数据，卸载应用也会删除这些本机数据。

输入联想和主动搜索都会调用地点查询，因此联网查询可以发生在用户启动到站守候之前。当前代码在取得已授权的最近位置时，为 Photon 请求附加经纬度，为高德请求附加转换后的坐标。缺少位置时仍可按文字查询。以上是源码中的条件行为，不代表已经抓包验证某一设备或 Release 产物。

附近位置读取要求精确位置权限，来源是系统保存的 GPS/网络最近定位；代码选择时间较新者，但没有检查其新鲜度，不能称为必然实时的位置。输入联想也没有先排除坐标或分享链接文本，因此用户直接粘贴的这类内容可能作为查询文字发送，不能声明坐标文本只进入反查路径。

原搜索路径在配置高德 Web Key 时先查询高德 Web 服务；没有有效结果或发生已处理的网络错误时继续尝试 Photon，随后可能调用系统 Geocoder。配置了高德 Android Release Key 并由用户主动同意切换时，改走单独的高德搜索 SDK；应用传入搜索词和可选城市，不主动传入附近位置。

用户导入带坐标的目的地时，当前代码还会将目的地经纬度传入系统 Geocoder 反查地址。这是目的地坐标，不应自动等同于用户的实时位置。该系统调用发生在目的地确认框出现之前，不以当前定位权限为条件；取消确认不能撤回已经发生的调用。系统服务是否联网、实际提供方和请求内容需要设备证据。到站距离计算本身在设备上完成。

## 数据处理声明

- 传输安全：Photon/高德源码端点为 HTTPS，应用 Manifest 禁止自身明文流量；这不能证明另一个系统进程提供的 Geocoder 或系统定位服务使用何种传输方式，仍需分别核验。
- 数据共享：第三方地点服务是完成用户发起查询所需的直接接收方；是否在 Console 计作“共享”必须按当前 Data Safety 例外条件人工确认，不能仅因没有自建后端而回答“无共享”。
- 临时处理：即使第三方仅为实时查询临时处理，离开设备的数据仍应进入问卷评估。
- 删除：应用内“清空数据”删除本机任务、最近地点和设置；应用无法代替用户删除第三方服务可能保存的请求记录。
